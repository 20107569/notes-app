# Notes App

A console Notes app developed using Kotlin.

## Features

### V1.0
- Add a note
- List all notes
- Update existing notes
- Delete notes
- Mark notes as active / archived
- Input validation using helper functions
- Application logging

### V2.0
- V1.0 Features
- Archive notes
- Find a note by its ID
- Count all notes
- Count archived notes
- Count active notes
- Unit testing using JUnit 5
- Archive a note
- View all notes
- View active notes
- View archived notes

## Technology Used

- Kotlin
- IntelliJ IDEA
- Gradle
- Git & GitHub
